# The Career Architect

Base visual oficial del proyecto.

## North Star
- Sanctuary UI para búsqueda laboral.
- Estética editorial premium.
- Asimetría intencional.
- Profundidad tonal en lugar de bordes duros.

## Color Strategy
- Base: `surface` y `surface_container_low`.
- Módulos: `surface_container`.
- Interacciones principales: `surface_container_lowest`.
- CTA: gradiente de `primary` a `primary_container`.
- Nunca usar negro puro ni bordes pesados.

## Rules
- No usar `1px solid` para dividir secciones.
- Separar módulos por cambio tonal y espacio.
- Preferir “ghost borders” con `outline_variant` al 15%.
- Header y footers con blur y transparencia.

## Typography
- Headlines: `Manrope, Inter, ui-sans-serif, system-ui, sans-serif`
- Body: `Inter, Manrope, ui-sans-serif, system-ui, sans-serif`
- Headlines con tracking `-0.02em`.

## Components
- Badges redondeados completos.
- Botón primario con gradiente.
- Inputs con fondo tonal y barra activa inferior.
- Cards y listas sin divisores.
